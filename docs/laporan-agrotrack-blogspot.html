📋 Laporan Penggunaan Aplikasi AgroTrack

AgroTrack adalah aplikasi desktop berbasis C# / WPF (.NET 8) yang dikembangkan sebagai Tugas Evaluasi Tengah Semester (ETS) mata kuliah Pemrograman Berbasis Kerangka Kerja (PBKK). Aplikasi ini dirancang untuk membantu pengelola pertanian dalam merencanakan, mencatat, dan memantau seluruh siklus produksi — mulai dari lahan, musim tanam, aktivitas lapangan, stok bahan, biaya operasional, hingga hasil panen dan laporan laba rugi.

🛠 Teknologi yang Digunakan:
C# 12 / .NET 8 LTS WPF (XAML) MVVM Architecture SQL Server Express ADO.NET PBKDF2 Security

1. Cara Login ke Aplikasi

Saat pertama kali membuka AgroTrack, pengguna akan disambut halaman login dengan tampilan dua panel: panel kiri menjelaskan fitur-fitur AgroTrack, dan panel kanan berisi form login.

Langkah Login:

1 Buka aplikasi AgroTrack.exe dari folder instalasi.
2 Pastikan SQL Server berjalan — aplikasi membutuhkan koneksi ke database AgroTrackDb.
3 Masukkan Username dan Password di panel kanan.
4 Klik tombol "Masuk ke Sistem".
5 Tersedia tombol demo cepat: Admin, Manajer, dan Petugas untuk mengisi kredensial otomatis saat pengujian.

Akun Demo yang Tersedia:

PeranUsernamePasswordHak Akses
AdministratoradminAdminPassword@123Seluruh modul, termasuk manajemen pengguna
ManagermanagerManagerPassword@123Dashboard, master data, musim tanam, laporan
Petugas LapanganpetugasPetugasPassword@123Aktivitas lapangan, penggunaan bahan, panen
⚠️ Jika login gagal dengan pesan "Instance failure", pastikan layanan SQL Server (SQLEXPRESS) sudah berjalan dan port 1433 aktif.

2. Tampilan Utama Setelah Login

Setelah berhasil login, pengguna masuk ke shell utama aplikasi yang terdiri dari:

  • Sidebar kiri — navigasi menu utama dengan dua bagian: Operasional dan Logistik & Keuangan
  • Header atas — menampilkan breadcrumb halaman aktif, tombol ganti tema (Light/Dark), dan tombol Keluar
  • Area konten — menampilkan halaman sesuai menu yang dipilih
  • Footer sidebar — menampilkan nama dan peran pengguna yang sedang login

3. Fitur-Fitur Aplikasi

📊 3.1 Dashboard

Halaman pertama setelah login. Menampilkan ringkasan operasional pertanian secara real-time langsung dari database.

Informasi yang ditampilkan:
  • Jumlah Lahan Aktif dan total luas (hektare)
  • Jumlah Penanaman Aktif yang sedang berjalan
  • Jumlah Aktivitas Hari Ini
  • Jumlah Bahan Menipis (stok di bawah batas minimum)
  • Total Hasil Panen (kg), Biaya Operasional, Pendapatan, dan Estimasi Laba Bersih dalam format Rupiah
  • Grafik batang Target vs Realisasi Panen per musim tanam
  • Distribusi komoditas yang sedang ditanam
  • Daftar penanaman yang mendekati jadwal panen

🗺️ 3.2 Manajemen Lahan Pertanian

Modul untuk mendaftarkan dan mengelola data lahan pertanian yang dimiliki.

Data yang dicatat per lahan:
  • Kode lahan unik (contoh: LHN-001)
  • Nama lahan, lokasi, dan deskripsi
  • Luas lahan dalam hektare
  • Jenis tanah (Aluvial, Lempung Berpasir, Andosol, dll.)
  • Status lahan: Aktif, Istirahat, Pemeliharaan, Nonaktif
Fitur: Tambah, edit, hapus lahan. Lahan yang sudah terikat penanaman tidak dapat dihapus untuk menjaga integritas data.

🌾 3.3 Manajemen Komoditas

Modul untuk mendaftarkan jenis-jenis tanaman/komoditas pertanian yang dibudidayakan.

Data yang dicatat:
  • Kode komoditas unik (contoh: KMD-001)
  • Nama komoditas (contoh: Padi Ciherang, Jagung Manis Bonanza)
  • Satuan hasil panen (kg, ton, kuintal, pack)
  • Estimasi hari tumbuh hingga panen
  • Status aktif/nonaktif

📅 3.4 Manajemen Musim Tanam (Penanaman)

Modul inti yang mengelola siklus hidup lengkap setiap musim tanam — dari perencanaan hingga selesai panen.

Data yang dicatat:
  • Kode penanaman unik, nama musim tanam
  • Lahan dan komoditas yang digunakan
  • Tanggal mulai dan estimasi tanggal panen
  • Luas tanam (hektare) dan target hasil panen
  • Catatan tambahan
Status siklus hidup:
StatusKeterangan
DirencanakanPenanaman baru dibuat, belum dimulai
AktifProses penanaman sedang berjalan
Siap PanenTanaman siap untuk dipanen
SelesaiMusim tanam telah selesai
DibatalkanPenanaman dibatalkan (misal: bencana alam)
Validasi otomatis: Sistem mencegah penambahan luas tanam melebihi kapasitas fisik lahan dan mencegah irisan periode musim tanam aktif yang melampaui kapasitas lahan.

🚜 3.5 Aktivitas Lapangan

Modul pencatatan semua kegiatan teknis yang dilakukan di lapangan selama musim tanam berlangsung.

Jenis aktivitas yang bisa dicatat:
  • Persiapan lahan, Penanaman, Penyiraman
  • Pemupukan, Penyiangan, Pengendalian hama
  • Pemeriksaan tanaman, Panen
Data per aktivitas: Tanggal, durasi (jam), petugas yang bertugas, status (Terjadwal / Berlangsung / Selesai / Dibatalkan), dan catatan detail kegiatan.

📦 3.6 Manajemen Bahan & Stok

Modul inventaris untuk mengelola semua bahan pertanian yang digunakan.

Kategori bahan:
  • Benih (Seed)
  • Pupuk (Fertilizer)
  • Pestisida (Pesticide)
  • Fungisida, Herbisida
  • Alat habis pakai (ConsumableTool)
Data per bahan: Kode unik, nama, satuan, stok saat ini, stok minimum (batas peringatan), dan harga satuan.

Fitur stok atomik (ACID): Saat petugas mencatat penggunaan bahan pada aktivitas, stok otomatis berkurang. Jika pencatatan dibatalkan, stok dikembalikan — semua dalam satu transaksi database yang aman.

💰 3.7 Biaya Operasional

Modul pencatatan semua pengeluaran yang terjadi selama musim tanam, terhubung langsung ke data penanaman.

Kategori biaya:
  • Tenaga kerja
  • Sewa alat (traktor, mesin perontok, dll.)
  • Transportasi
  • Irigasi
  • Bahan bakar, Perawatan
Semua nominal ditampilkan dalam format Rupiah (Rp X.XXX.XXX). Hanya dapat diakses oleh Administrator dan Manajer.

🌽 3.8 Hasil Panen

Modul pencatatan realisasi panen — mendukung panen bertahap (multiple batch per satu musim tanam).

Data yang dicatat per sesi panen:
  • Tanggal panen
  • Jumlah hasil panen (kg/satuan komoditas)
  • Kualitas panen: Grade A, Grade B, Grade C
  • Harga jual per satuan
  • Total pendapatan (otomatis dihitung: Jumlah × Harga)
  • Catatan tambahan

📈 3.9 Laporan Produksi

Laporan komprehensif per musim tanam yang menampilkan analisis finansial lengkap.

Informasi dalam laporan:
  • Target produksi vs realisasi aktual (dalam kg & persentase pencapaian)
  • Total biaya operasional (perincian per kategori)
  • Total biaya bahan pertanian yang digunakan
  • Total pendapatan dari panen
  • Laba/Rugi Bersih = Pendapatan − (Biaya Operasional + Biaya Bahan)
  • Grafik perbandingan antar musim tanam
Hanya dapat diakses oleh Administrator dan Manajer.

👥 3.10 Manajemen Pengguna

Modul khusus Administrator untuk mengelola akun pengguna sistem.

Fitur:
  • Membuat akun pengguna baru dengan peran tertentu
  • Mengubah peran pengguna (Administrator / Manager / Petugas Lapangan)
  • Reset password pengguna
  • Aktifkan / nonaktifkan akun
  • Sistem mencegah admin menonaktifkan akun dirinya sendiri (self-lockout protection)

4. Fitur Tambahan UI/UX

  • 🌙 Dual Theme (Light/Dark Mode) — dapat diganti kapan saja dari header atas
  • 🔍 Pencarian & Filter — tersedia di setiap halaman daftar data
  • 📄 Pagination — data ditampilkan per halaman agar tidak memberatkan sistem
  • ⏳ Loading State — indikator loading saat mengambil data dari database
  • 📭 Empty State — pesan informatif ketika data kosong atau filter tidak menemukan hasil
  • ❌ Error State — pesan error dengan tombol Coba Lagi
  • ✅ Toast Notification — notifikasi sukses/gagal setelah aksi
  • 🗑️ Dialog Konfirmasi — konfirmasi sebelum menghapus data penting

5. Arsitektur & Keamanan

Pola Arsitektur MVVM

Aplikasi menggunakan pola Model-View-ViewModel (MVVM) secara murni — tidak ada kode bisnis di code-behind XAML. Semua logika ada di ViewModel dan Service layer.

Keamanan Password

Password disimpan menggunakan enkripsi PBKDF2 dengan:

  • Salt kriptografis unik 16-byte per pengguna
  • 100.000 iterasi SHA-256
  • Tidak ada plain-text password yang tersimpan di database

Keamanan Database

  • Seluruh query menggunakan Parameterized Query — aman dari SQL Injection
  • Transaksi stok menggunakan UPDLOCK untuk mencegah race condition
  • Foreign key constraint mencegah penghapusan data yang masih direferensi
